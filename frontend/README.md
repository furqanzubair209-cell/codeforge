# CodeForge — frontend

This is the deployable web app (React + TypeScript + Vite + Tailwind). It's the piece that gets deployed to Netlify.

See the [repo root README](../README.md) for the full project overview, environment variables, and deployment instructions for both this app and the separate execution service.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```
